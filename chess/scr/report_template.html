How to read these metrics
Policy cross-entropy
The network is trained to reproduce MCTS visit probabilities over moves. A diffuse target has nonzero minimum cross-entropy, even when copied exactly.
Policy KL
Cross-entropy minus target entropy: disagreement between MCTS targets and the full network output distribution. The game inspector instead compares search against policy renormalized over legal moves; those KL values are not directly comparable. Lower KL means closer imitation, not necessarily stronger chess.
Top-move agreement
The fraction of batch positions where the network’s highest-scoring action matches the target’s most visited move.
Value loss and means
Value loss is mean squared error against final outcomes, from the player-to-move perspective. Means can hide errors of opposite signs. Cutoff treatment is recorded in the run configuration. Under exclusion, unfinished positions train only the policy; real draws remain eligible zero targets. Value statistics use only eligible examples, and a batch with none has no value measurement. Compare value loss with the constant-zero predictor on those same examples; a smaller loss alone may reflect a different target mix.
Gradient norm
The size of the raw update signal. It is useful for detecting spikes or a vanishing signal, but is not a performance score.
Fixed probes
The same positions are revisited as training progresses, without exploration noise. They expose changing choices but are only a small diagnostic set, not an Elo measurement.
